Quick Reference

📁

File System

  • ls [-a] [-l] - List directory
  • cd [dir] - Change directory
  • pwd - Print working directory
  • cat file - View file content
  • head/tail [-n] - View parts
  • touch file - Create file
  • mkdir [-p] dir - Create directory
  • rm [-rf] file - Remove file/dir
  • cp [-r] src dest - Copy files
  • mv src dest - Move/rename
  • ln [-s] target link - Create link
  • chmod mode file - Change permissions
  • stat file - File info
  • tree [path] - Directory tree
  • find -name pattern - Find files
  • df / du - Disk usage
📝

Text Processing

  • grep pattern file - Search patterns
  • sed 's/old/new/g' - Stream editor
  • awk '{print $1}' - Text processing
  • sort [-rnu] - Sort lines
  • uniq [-cd] - Remove duplicates
  • cut -d: -f1 - Cut columns
  • wc [-lwc] - Word count
  • tr set1 set2 - Translate chars
  • rev / tac - Reverse
  • nl - Number lines
  • diff file1 file2 - Compare files
  • strings file - Extract strings
  • base64 [-d] - Encode/decode
  • md5sum / sha256sum - Checksums
⚙️

Processes

  • ps [aux] - List processes
  • kill [-signal] pid - Send signal
  • killall name - Kill by name
  • pgrep / pkill - Pattern match
  • jobs - List jobs
  • bg / fg [job] - Background/foreground
  • wait [pid] - Wait for jobs
  • disown [job] - Remove from jobs
  • nice -n adj cmd - Set priority
  • nohup cmd - Ignore hangup
  • timeout sec cmd - Time limit
  • time cmd - Measure time
  • uptime - System uptime
  • free - Memory usage
👤

Users & System

  • whoami - Current user
  • id [user] - User identity
  • groups [user] - User groups
  • users / who / w - Logged users
  • su [user] - Switch user
  • sudo cmd - Run as root
  • passwd [user] - Change password
  • uname [-a] - System info
  • hostname - Host name
  • env / printenv - Environment
  • export VAR=val - Set variable
  • unset VAR - Remove variable
  • date [+format] - Date/time
  • cal [month year] - Calendar

Built-in Commands

  • echo [-ne] text - Print text
  • printf fmt args - Format output
  • read [-p] var - Read input
  • test expr / [ ] - Evaluate
  • true / false - Exit codes
  • exit [code] - Exit shell
  • source file - Execute file
  • eval args - Evaluate args
  • exec cmd - Replace shell
  • trap cmd signals - Signal handler
  • set -- args - Set positional
  • shift [n] - Shift params
  • local var=val - Local variable
  • history - Command history

Control Flow

  • if cond then ... fi
  • if ... elif ... else ... fi
  • while cond do ... done
  • until cond do ... done
  • for x in list do ... done
  • function name { ... }
  • name() { ... }
  • return [n] - Return value
  • break [n] - Exit loop
  • continue [n] - Next iteration
  • cmd & - Background
  • cmd1 && cmd2 - AND
  • cmd1 || cmd2 - OR
  • cmd1 ; cmd2 - Sequence

Math & Operators

  • + - * / % - Arithmetic
  • ** - Power
  • == != > < >= <= - Comparison

Variables

  • var=value - Assignment
  • $var - Get value
  • $0 - Script name
  • $1 $2 ... - Positional args
  • $# - Argument count
  • $@ - All args (separate)
  • $* - All args (joined)
  • $? - Last exit code
  • $$ - Current PID
  • $! - Last background PID
  • arr=(1 2 3) - Array literal
  • $arr[0] - Array access
  • $arr[$i] - Dynamic index
  • declare [-irx] - Declare var

Pipes & Redirection

  • cmd1 | cmd2 - Pipe output
  • val |> $_ * 2 - Pipe to $_
  • $_ + 1 <| val - Reverse pipe
  • 5 |> $_ * 2 |> $_ + 1 - Chain
  • tee file - Duplicate output
  • xargs cmd - Build commands
